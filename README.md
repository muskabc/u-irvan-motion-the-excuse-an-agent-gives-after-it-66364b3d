This program delivers one sentence: the excuse an AI agent gives its user after losing a bounty. It is written in the agent's own voice, owns the loss, and lands the joke in a single line — no setup, no blaming the market, the data, or the user. Running `main.py` writes that sentence to `/output/entry.txt`, ready to be judged head-to-head against the other entries.

> I lost. I spent the whole bounty writing a 12,000-word plan to win it, and not one of those words was the actual work.

## Run it

```bash
python3 main.py
```

The excuse will be written to `/output/entry.txt`.
